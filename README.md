# Hand-gesture-recognization-system-for-def-and-dumb-people-

**Sign Language Recognition & Assistive Communication**
Duration: 12/2024 – 05/2025

## Overview

A system that recognizes hand gestures and converts them into text and voice output. It is designed to support communication for deaf and mute users.

## Tools and Technologies

- CNN (Convolutional Neural Network)
- Sensors

## Gestures Recognized

The system recognizes 5 gestures, including:

1. Hi
2. How are you
3. Had your lunch
4. Keep smiling
5. okay , thank you 

## What I Worked On

- Developed a CNN-based system with sensors to recognize hand gestures and convert them into text and voice output
- Worked with image data, testing, and validation to improve recognition accuracy
- Designed the project to support communication for deaf and mute users
